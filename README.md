# MINESWEEPER by Kelompok AlproGacor77
Minesweeper classic game, based on Qt and C++ 

#### Download Tutorial:
1. Just download the 'Minesweeper-by-AlproGacor77.zip' file 
2. Extract the file
3. Open 'Minesweeper-by-alprogacor77.exe'
4. If 'Windows protected your PC' appear, click 'More info', then click 'Run Anyway'
5. Enjoy the game ^.^
